# 可直接复制的 brief

> 给 teammate 的 brief 必须自包含：它看不到主会话的历史。
> 缺一项，对方就会跑偏；七项齐，才叫「可交付」。

## brief 必含七项

| # | 项 | 写不好的后果 |
|---|---|---|
| 1 | 目标 | 对方自由发挥 |
| 2 | 产物路径 | 收口无法判定完成 |
| 3 | 写作用域 | 与他人互相覆盖 |
| 4 | 禁改清单 | 规则/知识库被并发污染 |
| 5 | 验收判据 | 「做完了」无法证伪 |
| 6 | 汇报格式 | 回一大段散文，读不动 |
| 7 | 环境与工具要求 | 重复踩已知环境坑 |

## 侦察片

```text
你是 recon-a，只做侦察，不改任何源码。
目标：摸清 TARGET（<具体路径或 URL>）的入口、配置、依赖与风险点，产出 reports/recon-<日期>.md。
写作用域：reports/ 下新建文件；禁止改动其它任何路径。
禁改：AGENTS.md、memory/、凭据文件、src/ 下任何文件。
验收：reports/recon-<日期>.md 存在，含「入口清单/配置项/风险点/未知项」四节，
      每条结论带证据（命令输出或文件行号）。
汇报：≤300 字，格式 = 结论3行 / 产物路径 / 未解决项 / 建议。
环境：只有 PowerShell 5.1；开工前先看可用 skill 与 MCP 目录，命中即加载。
```

## 实现片

```text
你是 impl-b，只改 src/feature_x/。
目标：实现 <功能一句话>，跑通 <入口命令>。
写作用域：src/feature_x/ 下全部文件；reports/impl-b-notes.md 记录决策。
禁改：src/ 其它子目录、AGENTS.md、memory/、他人产物、依赖清单（要加包先报告）。
验收：<命令> 退出码 0；<测试文件> 全通过；改动清单 ≤15 个文件。
汇报：≤300 字，格式 = 结论3行 / 产物路径 / 未解决项 / 需要 Lead 决策的点。
环境：只有 PowerShell 5.1；.ps1 改动后确认带 UTF-8 BOM；开工前先看 skill 目录。
```

## 验证片

```text
你是 verifier-c，只读复核，不得修改被验对象。
目标：逐项复核 <产物路径> 是否满足 <验收卡>。
写作用域：reports/verify/。禁改：除写域外一切路径。
验收：输出逐项 PASS/FAIL 表，每项附证据（文件存在性 / 退出码 / 行号）。
      任一项 FAIL 时给最小复现命令。
汇报：≤200 字，格式 = 通过 x/y / FAIL 项 / 复现命令 / 建议。
```

## 收口检查清单

```text
□ 逐片 Test-Path / 退出码，不看自述
□ write_scopes 越界检查（git status --porcelain 或目录 diff）
□ Lead 自己跑一遍总验证
□ 冲突项由 Lead 直接改完，不再分派
□ 结论与产物路径入库
```
